November 22, 2026. Owner reference for the 43 package galleries. Each line describes the starting scope customers can select. Retail comparisons are published online prices, not reserved inventory. Estimated labor hours are planning assumptions at $75/hour. Existing fixed task rates are retained. Freight, regional stock and site suitability require address-specific verification.

Newly itemized scopes use named products, quantities and sources in room-projects.js. Retail is marked up 35% once. Catalog prices already include markup. The existing calculator discounts labor, adds fees, and rounds up to the next $5. The Fees column includes rounding. Customer-supplied materials and custom work need their own estimate.

## Items needing confirmation

- Deluxe Accessibility assumes a 24-foot switchback, one new turnaround and suitable existing end landings. Confirm rise, footing conditions, rail layout and clearances on site.
- Bedroom, family room, garage and sunroom additions are standalone custom construction requests. A buildable dimensioned plan, foundation, tie-in, utility and permit scope are needed before quoting construction.
- Local stock, freight and site measurements are open for product-based scopes. For playgrounds, shelters and pool/deck work verify the actual equipment, footprint, substrate, applicable site requirements and anchoring before a job quote.
