# Project package cost coverage — November 5, 2026

This is a working audit of the full advertised work scope, **not** a new pricing approval. The package catalog contains **40 Basic + 40 Premium** generic scopes. Each Premium package includes all the Basic tasks plus the additional Premium tasks. **Only the Accent Walls Basic example has a complete line-item starting baseline at this checkpoint.** A missing price does not make a job free and must not be represented as a complete starting amount.

## Rules for a safe customer-facing starting price

1. Define a qualifying room or site size and the quantity of **every** item the package promises.
2. Price labor using current approved job rates; if no approved job price exists, record estimated hours at $75/hr as a review assumption, not a fixed owner-approved charge. Apply the $150 visit minimum where applicable.
3. Price materials using `material-price-reference.json` or a current verified product quote. The reference already includes the 35% markup; **never mark it up a second time**.
4. Price required **consumable** supplies from `data/approved-supply-prices.json`. Exclude reusable shop tools and avoid duplicate supplies; any incompatible or missing consumable needs an actual product price before sign-off.
5. Apply the advertised bundle discount **to labor only**. Existing draft tiers use 5% Basic, 7% Standard/Premium, 10% Kitchen Deluxe; confirm missing tiers before publication. Keep separately accounted project fees and do not charge them twice.
6. Save `startingAt`, the measured work, price basis, material/supply allowance, discounted labor and project fees to cart. A starting price is an estimate, not a collectible charge. Supplier stock, shipping, taxes and final scope still need confirmation.
7. If any **mandatory promised item** has an unpriced fixture, material, structure or scope, keep that package in quote-required status until a conservative provisional allowance is explicitly approved. Do **not** silently exclude it to create a misleading starting price.

## First fully priced baseline

**Accent Walls — Basic (sound existing 12 × 8 ft interior wall, 96 sq. ft.):**

- Labor before discount $175.00, 5% labor discount $8.75, discounted labor **$166.25**.
- Reference-priced flat paint $48.60 and bonding primer $47.22: **$95.82**.
- Consumables: painter's tape $11.48, sandpaper $8.10, paint roller sleeves $18.90, tray liners $12.83: **$51.31**.
- Project fees + round-up to the next $5: **$36.62**.
- **Starting at $350.00**. No payment is collected in the cart. Silicone tub-and-tile caulk is unsuitable for a painted wall and excluded. Reusable paint tools and canvas cloths are not automatically billed.
